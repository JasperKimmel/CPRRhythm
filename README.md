# CPR Rhythm - Support

Welcome! This is the official support repository for **CPR Rhythm**, a free Apple Watch app that provides haptic guidance for CPR tempo.

## 📱 About the App

CPR Rhythm helps you maintain the correct rhythm (110 BPM) during chest compressions with:
- Haptic feedback on Apple Watch
- Visual progress tracking
- Breathing alerts after 30 compressions
